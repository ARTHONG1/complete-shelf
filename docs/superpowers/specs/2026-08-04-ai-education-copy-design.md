# AI 교육 서가 텍스트 리브랜딩 설계

## 목표

기존 Complete Shelf의 시각 디자인과 Three.js 상호작용을 그대로 보존하면서, 모든 사용자 노출 문구를 한국어 AI 교육 소개 콘텐츠로 교체한다.

## 변경 경계

변경 대상은 `index.html`의 문자열과 `README.md`의 설명 문구뿐이다.

다음 요소는 변경하지 않는다.

- CSS 규칙, 레이아웃, 반응형 중단점
- 책 색상, 재질, 크기, 위치, 표지 모티프
- 이미지 아틀라스와 에셋
- Three.js 버전과 모듈 import
- 지오메트리, 카메라, 조명, 렌더링 설정
- 애니메이션과 상태 전환
- 마우스, 키보드, 페이지 넘김 상호작용
- 접근성 DOM 구조와 ARIA 역할

## 유지되는 물리적 메타데이터

책의 실제 색상과 모델을 설명하는 `binding`, `format`, `motif`, `paletteLabel` 문자열은 현재 시각 요소와 대응하므로 변경하지 않는다. `id`, `motifKey`, 색상, 팔레트, 폭, 높이, 깊이, 시드도 그대로 유지한다.

## 접근성 문구

버튼, 상태 안내, 라이브 영역의 문구를 한국어로 교체한다. ARIA 역할, 속성, 포커스 처리 방식은 변경하지 않는다. 주요 용어는 다음과 같이 통일한다.

- Volume → 권
- Previous/Next volume → 이전 책/다음 책
- Open → 자세히 보기
- Open/Close book → 책 열기/책 닫기
- Previous/Next sample page → 이전 페이지/다음 페이지
- Return volume to shelf → 서가로 돌아가기
- Reset view → 시점 초기화

## README

README는 `AI 교육 서가`의 목적, 일곱 주제, 로컬 실행 방법, 원본 저장소와의 관계, 변경하지 않은 시각·상호작용 기반을 설명한다. 원본 코드의 명시적 라이선스가 없음을 숨기거나 새 라이선스를 임의로 부여하지 않는다.

## 오류 처리

WebGL 미지원, 그래픽 컨텍스트 손실, 초기화 실패 시의 정적 카탈로그 안내도 한국어로 교체한다. 오류 처리 로직과 fallback 동작은 변경하지 않는다.

## 검증

1. 자동 문자열 테스트가 전역 문구와 일곱 권 데이터를 확인한다.
2. 이전 도구명과 기존 사이트명이 사용자 노출 영역에서 제거됐는지 확인한다.
3. `git diff --unified=0`으로 승인된 문자열과 문서 외 변경이 없는지 검토한다.
4. 로컬 서버에서 서가 이동, 상세 보기, 책 열기, 페이지 전진·후진, 책 닫기, 서가 복귀를 완주한다.
5. 데스크톱과 좁은 화면에서 한국어 제목 잘림과 버튼 겹침을 확인한다.
6. 브라우저 콘솔 오류가 0건인지 확인한다.
7. 원본 GitHub 링크가 올바른 주소를 가리키는지 확인한다.
